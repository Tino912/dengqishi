### 三、这轮踩的坑 / 关键手法

1. **加道具绝对不能直接往 `level["props"]` 里塞**。`props` 里每一项都要
   `_decor_rng.randi_range` 抽 seed，而 `_decorate()` 又会躲开已有道具 120px ——
   提前加会让**整关装饰换位置**，依赖装饰的像素断言成片变红。
   → 宝箱改成**单独的 `chests` key**，并且在 `_decorate()` **之后**才入 `props`，用独立的
   `_chest_rng`。实测加完之后报告的既有数字逐字节未变。
2. **宝箱故意不 solid**。设成实心会插进 `collide_wall` 的推挤，而动线/撞墙那几条断言
   是拿现有道具布局量出来的，多一个实心体就可能把玩家顶到别处。
3. **随机源要分家**：`_rng`(主仿真) / `_decor_rng`(装饰) / `_shop_rng`(商店) / `_chest_rng`(宝箱)。
   商店与宝箱的 roll **绝不能走 `_rng`** —— 那是主仿真流。
4. **`_pump` 现在有三种"冻结世界的界面"要处理**：`dialogue`、`draft`（**开宝箱也走这个状态**）、
   `shop`。少点一种，后面所有段落成片变红。`_pump(n, hold, auto_draft, auto_dialogue, auto_shop)`。
5. **`_draft_input` 每次按 Q/E 都会重调 `show_draft()`** —— 不把文案一起带上，
   **宝箱面板一按方向键就退回三选一的标题**。→ 文案存在 main 上（`_panel_title/_sub/_hint`），
   三选一与宝箱共用 `_redraw_panel()`。已固化成回归断言。
6. **对白会把面板挡在后面**：`interact()` 先推对白再推 shop 事件 → `_request_shop()` 看到
   state=="dialogue" 就挂 `_pending_shop`，对白讲完再补开。
   顺手把三个面板的收尾逻辑合并成 `_resume_play()`（对白→三选一→宝箱→商店→结算）。
7. **两处自己写代码时的失误**（记下来提醒自己）：
   - 用 `Edit` 做"在前面插入函数"时，**误把被插入函数的第一行删掉了**（两次，
     `_chip_sb` 与 `_statue`）。插入新函数时 `old_string` 要包含足够上下文且
     `new_string` 要**原样重复**那一行。
   - GDScript 字符串里不能裸用双引号：`"…挂在"手上"…"` 直接 parse error，要用「」。

### ⚠️ 沙箱里改不了远程（重要，会反复遇到）
执行 `git push/pull` 会连撞两层墙：
1. **`/etc/ssh/ssh_config.d/20-systemd-ssh-proxy.conf` 报 "Bad owner or permissions"**
   → 它是符号链接，目标是 `-rw-r--r-- nobody nobody`。OpenSSH 校验 include 文件属主必须是
   root 或当前 uid，而沙箱把 root 文件重映射成 `nobody` → **这是沙箱副作用，用户自己的终端应该正常**。
   绕过办法：`GIT_SSH_COMMAND='ssh -F /dev/null ...'`（`-F` 会跳过 `/etc/ssh/ssh_config`）。
2. **命令以 uid=0 跑，但 `$HOME=/home/tino12`** → ssh 用 `getpwuid` 取家目录得到 `/root`，
   密钥在 `/home/tino12/.ssh/` 所以找不到。要显式 `-i /home/tino12/.ssh/id_rsa`。
   而**读私钥被沙箱拦下、用户当场拒绝授权** → 本轮 push 未能执行，也没造成任何远程改动。
   （实测网络是通的：ssh 已走到 `Permission denied (publickey)`，说明 22 端口连得上。）

**这轮对仓库的实际改动 = 0**：只建过两个本地备份分支（`backup/local-work`、
`backup/pr1-merged`），随后按用户要求 `git branch -D` 删掉了。工作区 97 项**自始至终未动**。
关键哈希备查：合并提交 `1a9f2a8`、PR 提交 `55cb837`、合并前 `7b95646`。
即使本地 ref 全丢也不怕 —— **GitHub 永久保留 `refs/pull/1/head` 与 `refs/pull/1/merge`**。
