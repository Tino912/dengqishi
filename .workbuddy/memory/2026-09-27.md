## 做了什么

  贴图 **G 通道**；着色器三个 `× alt` 旋钮：height_fall 0.85（越高越薄）、
  height_parallax 1.0（雾纹锚地面，按 z 像素错开）、height_mix 1.20（高处换浮雾层）。

## 1. 雾锚定（`fog.gd`）
- 旧：噪声采样 `SCREEN_UV × mist_scale` = **贴在屏幕上** → 主角一走整片雾跟着镜头平移。
- 新：`gw = (SCREEN_UV.x*view_w − view_w/2 + cam.x,
  (SCREEN_UV.y*view_h − view_h/2)/ysquash + cam.y + hz/ysquash)`；三个新 uniform
  `cam_xy` / `view_w` / `ysquash`，`sync()` **每步**重发 `cam_xy`。投影是仿射的 → 反解精确。
- ⚠️ 屏幕雾胞横竖不等（横向 55px、纵向被 y 压 0.62）→ 世界坐标里 y 要**除以 ysquash**。
- 自检 ②f：相机平移 83px，只比**同一帧内 `开雾 − 关雾`** 这一层。
  **正 0.0013 / 反 0.0250 = 19×**；对照图 `shots/26-fog-anchor.png`（3 格）。
- ⚠️ **比整帧是不行的**：抗锯齿在屏幕空间，平移过的画面永远不可能逐字节相同
  （地形差 0.0029，比"正"那条的 0.0013 还大 —— 拿它当判据必然误判）。

## 2. 伤害光圈（`art.gd` + `world.gd`）
- 飘字衬底辉光 1.20/0.30 → **0.85/0.22**；火花光晕 3.4/0.50 → **2.1/0.30**（能量 0.37 / 0.23）。
- 判据三条：真的在发光 · 剂量-反应（`glow_mul` 0 / 1 / 1.51）· 绝对上限
  （像素 424 → 上限 **1260**（旧尺寸 3742）；能量 0.00182 → **0.0044**；真实命中 554 → **1300**）。
- ⚠️ **飘字那处别收太狠**：`float_text` 顺序是 glow → 八向描边 → 字，辉光在字**底下**，
  可见的只有描边外的**外沿**。收 0.62 时外沿被字盖掉（整窗只有 115 px 亮、且大半来自火花）
  → `TEXT_GLOW_KEYS` 变成**看不见的死开关**。**只有看图 + 数像素能发现。**
- ⚠️ 端到端那一发要不要暴击由随机流决定 → **不写死种子**：抽到暴击就
  `w._rng.state = st` **退回抽之前**，让 `damage_enemy` 自己再抽到同一发，再断言"确实是暴击"。
- ⚠️ 光斑在亮底会饱和 → 判据带一条**前提断言**（窗里背景亮度实测 0.234 < 0.35）。

## 3. 倍速（`tools/godot-mutate.py`）—— 一半落地、一半被否
- **落地**：单轮 48.6 → **40.2 秒（1.21×）**。省掉 ① 每轮白跑的**导入刷新**（~8s：
  一键脚本拿"源码比类缓存新"当判据，而每个变异都会重写一个 src 文件 → 每轮必然成立，
  可变异从不新增 `class_name` 脚本）② `--disable-vsync`（~2.5s / 6%，逐字节相同）。
  → 改成**直接调引擎**，不走那个脚本。
- ⚠️ **更正旧账**：以前注释写"`--disable-vsync` 从 86 秒降到 40 秒（2.15×）"——
  那个 86 秒是**脚本总耗时**，跟**引擎耗时**不是一个口径。真话是 42.9 → 40.2（6%）。
- **被否**：`--jobs 4` 并发纸面 ~3×，实测**用不了**。是我给它加的**前提自证**拦下的：
  4 进程一起抢 XWayland 窗口尺寸时，基线断言
  `★ 前提：真窗口能被设成测试尺寸` **偶发**变红 → 含全屏断言的变异会被误判。
  → 改成**回退串行**（慢但可信），**不"重试到绿"**。
- ⚠️ **不要用 `unlink()` 保证"读到的是新报告"**：第一版这么写，撞沙箱批量删除保护，
  4 个 worker 各卡一次 → **整批跑挂、日志也没了**（只留一句
  `SAFE_DELETE_BULK_CONFIRM_REQUIRED`）。改成**只记 mtime、跑完必须变**（零删除）。
- ✅ 顺手修掉老坑：`main()` 里 `sys.stdout.reconfigure(line_buffering=True)` ——
  后台重定向不再块缓冲（以前日志一片空白，看着像"卡住"）。
