# 2026-09-27（雾的高度/体积/飘移 → 465/465）

接 09-26 的 F11 收尾。用户需求两句：「迷雾还只是一层会飘的灰，没有高度和体积」
+「顺便让迷雾可以动」。

## 做了什么
- `fog.gd`：世界空间高度场（每关烘一次，16px 格，152×121）→ `_rebuild` 写进照亮场
  贴图 **G 通道**；着色器三个 `× alt` 旋钮：height_fall 0.85（越高越薄）、
  height_parallax 1.0（雾纹锚地面，按 z 像素错开）、height_mix 1.20（高处换浮雾层）。
  关键设计：**只乘 alt → 纯地面拧任何旋钮逐字节不变**，对照从阈值变精确。
- 翻涌：两个慢 sin 加在噪声 y 上，0.70/13*720≈39px；0.35 时肉眼读不出（9.6%）。
- **MIST_SPEED 0.022 → 0.16**（「让雾可以动」）：贴地雾 ≈9px/s 东北、浮雾 ≈23px/s
  东南（两层反向）。0.022 时十几秒才挪一个雾胞（55px），读不出"在动"。
- `selfcheck.gd` 雾段新增 ②c 高度 / ②d 翻涌 / ②e 飘移：断言 442 → **465**，
  两遍跑 report.json 逐字节相同（md5 135b3aba…）。
- 变异 50 → **57**（雾 +7：G 通道不写 / 无视 fall / 去 parallax / 单层 / 判段反 /
  漂速 0 / 不写 mist_time）。

## 本轮坑（进 README 19.5 / MEMORY）
1. `get_shader_parameter()` 对"从没 set 过"的 uniform 返回 **null** 不是着色器默认值
   → MIST_SCALE/SPEED 在 GDScript 侧也写一份、_ready 显式下发。
2. 窗太小量的是单样本：40×24 装不下一个雾胞（55px），单相位差 2.4 倍
   → 屋顶窗 48×160 + 跨 3 相位平均。
3. 地面窗蹭到南边界墙屋顶带（alt 渐变）→"逐字节不变"变 2.8e-05；
   收窄到 90 高 + 两个窗各加前提断言。
4. `_region_moved` 默认 eps=0.10 对雾纹太钝（2 秒平均差才 0.003，moved=0）
   → 传小 eps 0.004，误报由字节级对照兜底。
5. 新坑（属"结构守卫"）：**断言段中途 runtime error 会静默截断该段后面所有断言**，
   checks_all_pass 照样 true。→ _run 里给每段加"跑到段尾"守卫断言。

## 段落守卫（新基础设施）
`_run()` 的每个 `await _section_*()` 后跟一行 `_section_done()`；`_finish()` 里断言
"全部 N 段都完整跑到了段尾"。截断时红的是它，不是成片莫名其妙的后段。
