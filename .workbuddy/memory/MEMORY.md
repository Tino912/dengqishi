## 是什么 / 权威归属
地图全黑、只有灯骑士周围些许亮光的游戏，**两份实现，故意的**：
- **Web 版** `src/`（Vite + TS + Canvas）：3 武器、三关数值、商店/升级/存档。
- **Godot 版** `godot-lightknight/`（4.7.2）：**跑在前面** —— 8 武器 / 19 技能 / 三选一 /
  精英词缀 / 种子随机布局 / 三关三图 / 5 元素与状态效果 / 攻击发光 / 夜色 / 迷雾 /
  F11 全屏，这些 Web 都没有。
⚠️ 旧约定「跨版本改玩法以 Web 为准」**已作废**；动之前先决定以哪边为准，**别默认 Web 是权威**。

## 硬约定
1. 根 `README.md` 是**用户给的原稿，不要覆盖**；实现说明另开文件（`IMPLEMENTATION.md`、
   `godot-lightknight/README.md`）。
2. 交付物必须**真跑起来**验证（真引擎 / 真浏览器），不接受「应该可以」，固化成一键脚本。
3. 多界面切换类缺陷（返回栈错乱 / 遮罩残留 / 结算被菜单吃掉）类型检查、构建、纯逻辑仿真
   都覆盖不了 → 必须真浏览器走完整交互流程。
4. 断言针对真实状态；累计计数用**基线增量**，别硬编码。
5. **全绿 ≠ 有意义**：写完断言必须跑一轮**变异测试**（改坏实现，确认只有对应断言变红）。
6. **绝对断言要与相对断言配对**：整片「比基准多多少」的断言，在基准被改坏时全都不响。
7. **变异"没红"要先分清三种情况**：① 补丁没打在生效的那一层；② **断言问错了问题**
   （对该失败方式天然不敏感）；③ **`expect`/`forbid` 抄错了断言名** —— 子串匹配不报错，
   会一路跑完才显示"预期变红却没有"，看着像"断言没牙"（实测白跑 27 分钟，
   而断言其实全红了，只是我多写了「★ 」前缀）。②要**让旋钮转一下** ——
   同一帧只改一个变量做前后对照，**不是把阈值调松**。
   推广：**量哪一层，就把别层冻住**（雾拉满后量夜色必须先关雾，
   否则量到的是雾 —— 实测夜色只剩 0.0086 的差别）。
   `tools/godot-mutate.py` 现在会在基线后**前置校验**断言名，对不上 40 秒就拦下。
8. **一条断言若被两个独立的层各能单独满足，它就是个没牙的烟测。**
   （2026-09-26 实例：「前摇 vs 挥出不一样」既被 `Art` 的 `sw["lean"]` 满足、
   又被 `world.gd` 跟着 `attack_t` 扫的刀光弧满足 → 把艺术层武器冻住它照样绿。
   修法是补 `alt` 单变量对照，并把原断言列进变异表的 `forbid` 注明"应该保持绿"。）
9. **像素判据别用整块均值**：细长物体（武器是根线）在窗里只占 1~2%，均值被空地
   稀释一个数量级（实测 0.0094，看着像"没动"）。改用**"动了多少"占比**，
   但**必须配 0 对照**（同一姿态重取一帧 / 场景里扫不到的区域），且只用在单变量对照上。
10. **绝对像素差随亮度成比例缩放 → 会"擦着阈值过"**，并让**无关的变异连带打红**
   （2026-09-26：「走路反相两帧的腿部差」被"夜色拧到最暗"与"挥击灯半径"两条无关变异打红）。
   **绝对判据要么按亮度归一化（`_region_diff_norm`），要么配相对对照。**
11. **断言"取错帧"会让它恒真/恒假，而外面看不出来。** 同日实例：「反相两帧的腿部差」
   取的是相位 0 与 4，但 `hip = sin(ph)*AMP` 在这两个相位**都是 0**（都是中立位）——
   于是它量到的其实是 sway/cloak，**把腿冻住也打不红**。
   ⚠️ **采样区只装你要盯的那一层**：窗里混进别的东西，"改坏该层"就不会红。
   排查顺序：它到底在量什么 → 窗里都有谁 → 判据是否需要归一化。
12. **同一个判断在 N 个地方各写一遍 → 迟早在第 N 处漏掉一处**（2026-09-26 实例：
   「这次挥击要不要画近战视觉」在 `_draw` 里写了三遍，①拦住了、③忘了，
   于是灯弩开火甩出一道 886px 宽的刀弧）。
   修法**不是**给漏掉那处补一个 `if`，而是收成**一个总闸函数**（`World.swing_visual_on()`），
   让 N 处都从它走；并且**在关键那一处的条件里刻意再问一次**（看着冗余）——
   它换来的是"这个缺陷永远有一条变异钉着"（注释里写明"这是变异锚点"）。
   推广：**判据只有一个出处时，才对得起"改坏它就会红"**。

## 八个最容易踩的坑（其余见 DETAIL-godot.md）
1. **沙箱「批量删除保护」**：**按 turn 累计**，同一条命令里删 >50 个（或同 turn 累计超 50）
   就被拦 —— 而且是**卡住等确认、不报错退出**（`scope":"turn"`）。覆盖式**写**多少个都不拦。
   → 还原 / 同步一律**覆盖式复制，只写不删**。
2. **`/tmp` 只有 10MB**（写满就崩，症状是「同样命令时好时坏」）+ 预置 `HTTP_PROXY/HTTPS_PROXY`
   会让本地回环 502 → `TMPDIR` / `--user-data-dir` / 截图输出一律放 `~/.cache/` 下，
   跑命令前先 unset 代理。
3. **自检里「少点一种冻结界面的自动点击」→ 后面成片变红**（敌人不动 / 镜头不跟 / 灯不亮），
   极难反查。会冻结世界的有四种：`dialogue`、`draft`（**开宝箱也是这个状态**）、`shop`、
   `World.waves_disabled`。
4. **`manual` 模式（`main.manual = true`）下世界冻结 → 特效会永远僵在最后一帧**。
   `effects` 里的 `slash` 会卡在 `life = 0.12` 一直画着（症状：走路 8 帧画廊里
   凭空多出一道黄色地面弧，`attack_t` 明明是 0）。拍"画廊"类截图前必须清
   `effects` / `texts` / `particles`（以及 `player.swing_cone = {}`），
   **并且补一条"画廊是干净的"断言**，否则下次还会中招。
5. **"看得出来"的判据用均值会被窗里的空地稀释 → 看着像"旋钮失灵"**。
   实测：同一个开关，600×420 的窗上均值只有 **0.0056**（阈值 0.01，判红），
   换成 `_region_moved` 占比 + 400×280 的小窗 → **4.63%**。
   **两种窗要反着用**："精确为 0" 用大窗（0 不受窗大小影响，越大越不漏），
   "看得出来" 用小窗（占比，窗大了被稀释）。
6. **加动作要加进 `GameInput.ACTIONS`，只 `_register()` 进 InputMap 不算**。
   采样只看 ACTIONS 那张表 —— 漏了它 `just()` 永远是 false，**键按下去毫无反应
   且不报任何错**。2026-09-26 又踩了一次（F11 就是这样"改了但没生效"的）。
   → 判据是端到端那条断言（"按下次数 0"），决策层的断言**全都不会红**。
7. **新加 `class_name` 的脚本必须先刷 `.godot/global_script_class_cache.cfg`**，
   否则报 `Parse Error: Identifier "xxx" not declared` —— 看着像"变量没声明"的语法错误，
   其实代码没问题，是类缓存旧。跑 `godot --headless --path <proj> --import`（约 10 秒）。
   一键脚本已自愈。
8. **哨兵（"不许静默变少"那种绝对断言）本身也要验有没有牙，而且"数什么"决定它有没有牙。**
   ① **段数哨兵没牙**：运行时错误只中断出错的那个函数，`_sec()` 里 `await f.call()`
   照样返回、段计数照样 +1 → 段内少跑一半它**无感**（实测 24 条断言消失、526→502，
   它报 ✓）。→ 改成数**断言条数**。
   ② **数"名字数"照样没牙**：`_checks` 是按名字索引的字典，**两条同名断言会塌成一条**
   → 把"同一个断言跑了两次"误报成"少跑了"；更糟的是报的原因写成"段内抛运行时错误"，
   **而那一轮根本没有运行时错误**（排查它会白追一个不存在的崩溃）。
   → 数 `_ok()` 的**调用次数**，并配一条**重名哨兵**（`名字数 == 调用次数`）。
   ⚠️ **断言名只要落在循环里，就必须把"这一圈是谁"编进名字**，否则后一圈**静默覆盖**前一圈
   —— 重名哨兵一上线就逮到一条真重名。
   ③ **测试辅助函数的失败出口也要把场面收干净**：`_ferry_sail()` 在"面板上没这一项"时
   直接 `return`，把面板开着留给下一个 `_pump()`（默认会自动选一项）→ 世界被重建 →
   调用方攥着的世界引用成**已释放对象** → 段内 `previously freed` → **后面 24 条断言静默不登记**。
