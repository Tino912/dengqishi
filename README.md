# LightKnight

*暂时的是现实，永恒的是理想.*

## Introduction
  LightKnight是一个游戏系列，它将经过迭代升级，成为一代游戏大作.
  这个系列将遵循由小渐大的原则，从简单走向多样，逐步将小小灯骑铸成匠心之作.
### V1
 第一代版本目标是做出一个拥有主线剧情的RPG，具备可玩的战斗系统与较吸引人的叙事性.  
 采取2.5D的俯视角.  
 初定为3张地图，分别叙述灯骑士的美好过往，遇难，踏上复仇.  
 需要实现：  
 1.地图/背景的简单制作  
 2.武器特效的正确性  
 3.人物动画的正确播放  
 4.怪物的正确生成与攻击动画  
 5.NPC及其交互性  
 6.物件的交互性  
 7.主线的连贯性  
 8.音效的正常播放
 实现顺序：背景与人物>怪物>武器>NPC>主线>物件  
 >注：出于创作的困难性考量，可以借用网络资源做替代，成品后再考虑替换.


## 以下为在学校时的记录，不代表成品
游戏：灯河（LightRiver）  
主角：灯骑士（LightKnight)
>少年受到诅咒

关卡：灯堡  
物品：灯火（货币），灯芯（点亮灯塔，让主角更强）  
灯塔：庇护所，存档，传送点等  
Boss：噬灯者  
NPC：掌灯人（即商人，点灯的） 
>可见，灯塔是一关打完才亮，没打完死了就回到上一灯塔。每个关卡即一张地图，一张图若干精英怪及一个Boss，一图打完通过”灯河“去到下一关。  
>打完前地图较暗，打完后地图以灯塔为光源散射照亮。

部分剧情：  
”你是受诅咒者，跟我们一样，是吃灯的家伙."——Boss1  
（引入盲女）
>盲女：古老灯芯所化，灭了，但与灯骑士能互相感应彼此

在其中一关，没灯芯，黑暗中怪和Boss不断再生  
灯骑士说：“天还能亮吗？”  
盲女：“会的”  
“可你不是看不见吗？”  
“可你在我身边时，我就感到格外亮堂”...  
Boss得知盲女是灯芯，吃了盲女，灯骑士救出盲女，但盲女已死，灯骑士点亮她，她点亮灯塔，化为灯骑士的力量.  

最终集齐很多灯芯，光芒刺醒灯神与灯魔。灯骑士打灯魔，解救灯神，灯神赐予灯骑士神力，灯骑士诅咒解除，变为原样。  
>或许盲女也能救？那以什么形式呢？

灯河过场词：“灯骑士啊，你是不幸的，可你亦是人们的希望，去吧，渡过灯河，去往更暗处带去光明吧。”  
>或许可以改得更高级些

掌灯人过场词：“尽情燃烧吧，你得为这个世界带去更多光亮！”

战斗机制：每把武器自带一套技能，技能需要连击数解锁使用，不同武器技能数与需要的连击数均不同  
灯芯升级灯骑士血量与亮度  
地图黑暗，只有灯骑士周围些许亮  
连击提高亮度，随时间变暗
