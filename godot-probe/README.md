# godot-probe —— 光照最小验证

这个工程只回答一个问题：**Godot 4 的 2D 点光会不会被墙体遮挡，以及亮度能不能在运行时调？**

结论是**会**，而且这恰好是 Web 版（Canvas 合成手搓的 `destination-out` 挖洞 + `lighter` 叠暖光）
做不到的事——Web 版的光**会穿墙**，因为没有遮挡关系。

```bash
tools/godot-probe.sh        # 一条命令跑完，产出截图 + 结论
```

需要 Godot 4.4+（**标准版即可**，不需要 mono/C#），以及可用的显示环境（X11 或 XWayland）。

---

## 怎么验证的

不靠"看起来对"，靠数字。工程里跑 6 个用例，**同一场景只改一个变量**：

| 用例 | 变量 |
|---|---|
| `shadow_on_add` | 基准：`shadow_enabled = true` |
| `shadow_off_add` | **对照组**：`shadow_enabled = false`，其余完全相同 |
| `shadow_on_mix` | 混合模式换成 `MIX` |
| `energy_high` | `energy` 1.2 → 2.6 |
| `inset_10` / `inset_24` | 遮挡体相对墙体**内缩** 10 / 24 像素 |

渲染走固定 1280×720 的 `SubViewport`，与窗口实际尺寸解耦
（否则窗口管理器会改画幅——实测被改成过 1270×1528，导致取样位置全错）。
每个用例等 8 帧稳定后，由**游戏自己**回读像素、存 PNG、写 `report.json`，
并通过 stdout 打印 `LKRPT…ENDLKRPT` 段。

## 实测结果

**光被墙挡住，掉 85%。** 墙后正对灯的位置（`C_behind`）：

```
开阴影  0.0482   ← 等于纯黑地板的底噪
关阴影  0.3308   ← 光直接穿过去了
```

同时远角（`D_corner`）两组都是 `0.0482` 不动 —— 说明变暗是**墙挡的**，不是光斑缩小。
把亮度提到 2.6 倍后墙后**依然是 0.0482**，阴影随亮度稳定成立。

**亮度可被运行时调节。** `energy` 1.2 → 2.6，画面均亮 0.2379 → 0.3805，
光斑明显变大变烫（见 `shots/energy_high.png`），而阴影形状不动。
这正是"连击提高亮度"需要的性质。

**混合模式差别不大。** ADD 均亮 0.2379，MIX 0.2268 —— MIX 稍微收敛一点，ADD 更"烫"。

## 一个必须知道的坑：墙会遮挡自己

如果遮挡体（`LightOccluder2D`）的轮廓和墙的视觉**完全重合**，
墙自己的表面会落进自己的阴影里 —— 因为从墙面上的点引向灯的射线，
会穿过这块墙自己的遮挡体。

实测：墙的迎面（`inset = 0`）亮度只有 `0.215`，往内两层直接掉到 `0.024`（= 未受光基准）。

**规律非常干净：受光深度 = 遮挡体的内缩量。**

| 遮挡体内缩 | d=2 | d=6 | d=20 | d=37 |
|---|---|---|---|---|
| 0 | 0.215 边缘光 | 0.024 影 | 0.024 影 | 0.032 影 |
| 10 | **0.409 亮** | **0.239 亮** | 0.024 影 | 0.032 影 |
| 24 | **0.409 亮** | **0.303 亮** | **0.232 亮** | 0.032 影 |

（d = 距墙左表面的像素数；0.0315 是未受光墙体的基准亮度）

而内缩**不会漏光** —— `inset_10` 与 `inset_24` 的墙后亮度都还是 `0.0482`。

所以这是个**可调的创作选择**，不是 bug：

- 遮挡体与墙重合 → 墙变成**边缘被勾亮的暗剪影**（在这种黑暗题材里很可能正是你要的）
- 遮挡体沿**墙脚（footprint）**放、与墙面视觉解耦 → 墙的迎面正常受光，影子照旧投出去

## 已知限制

- 这台机器没有独显，跑的是 **llvmpipe 软件渲染**（LLVM 22.1.8）。像素级数值（尤其是
  软阴影的过渡带）在真显卡上会有差异，上面那些**结论性判断**不受影响，
  但具体小数别当绝对值用。
- "受光深度 = 内缩量"这条是在**墙 = 屏幕空间矩形、灯在左侧**的配置下测的。
  2.5D 俯视（墙从墙脚向屏幕上方立起）时遮挡体该怎么摆 —— **已做第二个探针，见 [README-2.5D.md](./README-2.5D.md)**。
  结论摘要：要贴**画出来的整体轮廓**（不是地面足迹），且**只削底边**（不能四边均匀内缩，
  那会从墙顶漏光），削约 16px 即墙脚受光 13~15px。
- `CanvasModulate` 只压暗 `CanvasItem`，压不暗视口的清屏色 —— 所以地板这类
  接光面必须**显式画出来**，不能指望空背景被照亮。
